ADKreios
========

:author: NSLS-II / SPECS Integration

.. contents:: Contents

Overview
--------

ADKreios is an EPICS areaDetector driver for the SPECS KREIOS-150 momentum
microscope. It communicates with the instrument via the SpecsLab Prodigy
Remote In protocol (v1.22) over TCP.

The driver supports 1D (spectrum), 2D (image), and 3D (volume) data
acquisition across all operating modes: Spectroscopy, Momentum Microscopy,
and PEEM.

For full documentation, see the README.md in the ADKreios top-level directory.
